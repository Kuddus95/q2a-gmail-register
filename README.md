# q2a custom register plugin with gmail only for q2a site owner.
===============================================================

Plugin Version
--------------
- v1.1

This plugin will allow to register with gmail and verify users to protect spam registration. 

Installation Guide
------------------
- Extract zip file.
- Place directory called `q2a-gmail-register` in qa-plugin folder.
- Done

Question2Answer Version Required
----------------------------------------
Tested on q2a v1.8.8
php v8.1+ and above.

Admin Guide
-----------
- Login with admin id.
- Go to Admin > Plugins page.
- Scroll down to "Q2A Gmail Register" in plugin list.
- Click on check box and save.
- Done and enjoy.



Plugin Features
-----------------
Redirect users to gmail register page.
Send OTP to given gmail address.
Verify OTP and register form open.
Users get Registered and email confirmed.


- N.B: Only Gmail address is supported for registration.
